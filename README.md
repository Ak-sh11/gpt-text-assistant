# GPT-Powered Text Assistant

## Introduction

This project is a simple Generative AI application built using Python and the OpenAI API.

The application uses a GPT model to understand user questions and generate natural language responses.

## Features

- Accepts user input
- Sends prompts to a GPT model
- Generates AI responses
- Runs in the Python terminal
- Allows users to continue asking questions
- Type `exit` to close the application

## Technologies Used

- Python
- OpenAI API
- GPT Model

## How It Works

1. The user enters a question or prompt.
2. The Python application sends the prompt to the OpenAI API.
3. The GPT model processes the request.
4. The generated response is displayed to the user.
